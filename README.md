
# Task Manager

A student project from the Data Structure course. This console-based program simulates a task manager, allowing users to create, manage, and prioritize tasks using simple commands.

## Features
- Create, edit, and delete tasks
- View all tasks in a list
- Sort and prioritize tasks
- Interactive console-based interface

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MahdiIranpour/task-manager.git
   ```

2. Navigate to the project directory:
   ```bash
   cd task-manager
   ```

3. Compile and run the Java program:
   ```bash
   javac TaskManager.java
   java TaskManager
   ```

## Usage

After running the program, use the following commands:

- `add <task_name>`: Add a new task
- `edit <task_id> <new_task_name>`: Edit an existing task
- `delete <task_id>`: Delete a task
- `list`: List all tasks
- `exit`: Exit the program
